# PAwR Experiment Statistics

Consolidated PDR (Packet Delivery Ratio) and signal-quality results across all
experiments run so far. PDR is computed per node as `received / expected`,
where `expected = max(seq) - min(seq) + 1` over the observation window (the
only ground truth PAwR/BLE gives us for "how many responses should have
arrived"). Source data and full narrative context for each run lives in
`NOTES.md`; raw logs are in `logs/`. This file is the numbers-only summary,
regenerated by directly parsing the raw logs/CSVs — not hand-transcribed.

---

## 4. +8dBm TX power, full 17-node fleet, 34 subevents (2026-08-09)

Same redundant-slot fleet as above, `CONFIG_BT_CTLR_TX_PWR_PLUS_8=y` added.

**30-min soak: 3190 / 3207 = 99.47% PDR**, all 17 nodes present the entire
session, zero dropouts. 12/17 nodes hit a perfect 100%; worst node (54) was
96.81%. A confirmed **+2.7 percentage-point improvement** over the 0dBm
redundant-slot baseline (96.79%) at the same 34-subevent scale.

### Single-node distance sweep that motivated +8dBm (branch `distance-test-17slot`)

| distance | PDR @ 0dBm | PDR @ +8dBm |
|---|---:|---:|
| 1 m   | 82.4% | 96.9% |
| 1.5 m | 71.0% | 91.9% |
| 2 m   | 78.3% | 89.0% |

## Summary — best PDR by configuration

| configuration | overall PDR |
|---|---:|
| 34 subevents, redundant slots, +8dBm, 17 nodes (30-min soak) | **99.47%** |
| 34 subevents, redundant slots, 0dBm, 17 nodes (30-min soak) | 96.79% |
| 34 subevents, redundant slots, 0dBm, 17 nodes (10-min, primary+backup) | 98.25% |
| 20 subevents, fixed table, 6/6 buffers, ~13 nodes | ~89.4% |
| 20 subevents, dynamic (first-free-slot), ~12 boards, 90-min soak | 95.13% |
| 11 subevents, fixed table, no redundancy, walking | 90.26% |
| 11 subevents, dynamic, no redundancy, walking | 80.87% |
| 11 subevents, no redundancy, stationary (ring-2 runs) | 65-73% |
| 10 subevents, default buffers | 71.3% |
| 5 subevents (stock-like baseline) | 97.3% |

Redundant primary+backup slots + higher TX power is the strongest lever found
so far (99.47%). The 11-subevent ring-2/walking numbers are all
lower than the 17-node soaks above, most likely reflecting a harder RF
environment (walking, longer range, no redundancy) rather than a regression —
nodes 15/23 (back-worn) are the consistent weak points across every run they
appear in.
